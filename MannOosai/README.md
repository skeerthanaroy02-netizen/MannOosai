# MannOosai 🌱

A Vite + React frontend prototype for the MannOosai hackathon project.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Current screens

- Landing page with the supplied rice-field background
- Soil Health dashboard
- Soil Safety / Chemical Screening dashboard
- Responsive mobile navigation
- Illustrative score, waveform, metrics, and before/after sections

The current values are demo data. Hardware/API integration can be connected later.
